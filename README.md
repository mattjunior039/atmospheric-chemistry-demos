# Atmospheric Chemistry — Live Class Demos

Two presenter-controlled, projector-friendly demonstrations for Sections 18.1–18.2:

1. [Ozone vs. chlorine](https://mattjunior039.github.io/atmospheric-chemistry-demos/#ozone): show how a catalyst can destroy multiple ozone molecules.
2. [Molecular vibrations in 3D](https://mattjunior039.github.io/atmospheric-chemistry-demos/#vibrations): compare infrared-active and inactive vibrations.

Allow about two minutes per demo. Both are simplified teaching models: the ozone simulation is qualitative, and molecular motion is exaggerated.

The [live site](https://mattjunior039.github.io/atmospheric-chemistry-demos/) is self-contained and has no external dependencies. For offline use, download `index.html` and open it in a browser.

Presenter keys: `F` toggles full screen, `R` reveals an answer, and `PgDn`/`PgUp` changes the demo.
