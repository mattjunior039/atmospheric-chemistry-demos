# Atmospheric Chemistry — Live Class Demos

Presenter-controlled, projector-friendly demos for an interactive lecture on atmospheric chemistry (textbook Sections 18.1–18.2).

**Live site:** https://mattjunior039.github.io/atmospheric-chemistry-demos/

`index.html` is self-contained, with no external dependencies. It also works offline: download it and open it in any browser.

Keys: `F` full screen · `R` reveal answer · `PgDn`/`PgUp` next or previous demo.

CO₂ data: NOAA Global Monitoring Laboratory, Mauna Loa monthly means (https://gml.noaa.gov/ccgg/trends/), embedded snapshot. The atmosphere, ozone and smog modules are simplified teaching models.
